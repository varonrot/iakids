Fracciones: qué son, cómo se calculan y cómo aprenderlas

Las fracciones permiten representar partes de un todo y aparecen en muchos contenidos de matemáticas de primaria. Comprender qué significan antes de memorizar reglas facilita comparar, sumar, restar, multiplicar y resolver problemas con mayor seguridad.

Qué es una fracción

Una fracción representa una o varias partes de un todo dividido en partes iguales. Por ejemplo, si una pizza se divide en 8 partes iguales y tomamos 3, podemos representar esa cantidad como 3/8.

Una fracción no es solo dos números separados por una línea.

Representa una relación entre una cantidad de partes y el número total de partes iguales en las que se ha dividido el todo.

Numerador y denominador

ParteQué indica
NumeradorCuántas partes se toman
DenominadorEn cuántas partes iguales se divide el todo
Ejemplo: 3/5

El 3 es el numerador: tomamos 3 partes. El 5 es el denominador: el todo está dividido en 5 partes iguales.

Cómo leer fracciones

1/2 → un medio

1/3 → un tercio

3/4 → tres cuartos

5/8 → cinco octavos

7/10 → siete décimos

Representar fracciones visualmente

Los modelos visuales ayudan a entender que el denominador representa partes iguales. Podemos usar círculos, rectángulos, barras o conjuntos de objetos.

Importante: si las partes no son iguales, la representación no corresponde correctamente a una fracción del todo.

Fracciones propias e impropias

TipoEjemploIdea
Propia3/5El numerador es menor que el denominador
Impropia7/4El numerador es mayor o igual que el denominador

Fracciones equivalentes

Dos fracciones son equivalentes cuando representan la misma cantidad aunque utilicen números diferentes.

1/2 = 2/4 = 3/6

Podemos obtener fracciones equivalentes multiplicando o dividiendo el numerador y el denominador por el mismo número distinto de cero.

Cómo comprobar fracciones equivalentes

¿Son equivalentes 2/3 y 4/6?

Sí. Multiplicar 2/3 por 2/2 produce 4/6.

Simplificar fracciones

Simplificar significa expresar una fracción equivalente con números más pequeños.

Ejemplo:

6/8 puede dividirse entre 2 arriba y abajo: 3/4.

Comparar fracciones con el mismo denominador

Cuando el denominador es igual, la fracción con mayor numerador representa más partes del mismo tamaño.

5/8 > 3/8

Comparar fracciones con el mismo numerador

Cuando el numerador es igual, un denominador más pequeño significa partes más grandes.

3/4 > 3/8

Comparar fracciones con denominadores diferentes

Podemos utilizar representaciones, fracciones equivalentes o un denominador común.

Ejemplo:

1/2 y 3/4. Como 1/2 = 2/4, entonces 3/4 > 1/2.

Fracciones en la recta numérica

Situar fracciones en una recta ayuda a entender que son números y no solo partes de dibujos. Entre 0 y 1 existen muchas fracciones.

Suma de fracciones con el mismo denominador

Se suman los numeradores y se mantiene el denominador.

2/7 + 3/7 = 5/7

Suma de fracciones con distinto denominador

Primero necesitamos expresar las fracciones con un denominador común.

Ejemplo:

1/2 + 1/4

1/2 = 2/4, así que 2/4 + 1/4 = 3/4.

Resta de fracciones con el mismo denominador

Se restan los numeradores y se conserva el denominador.

6/9 − 2/9 = 4/9

Problemas con fracciones

Problema:

Una botella estaba llena. Se bebieron 3/8 por la mañana y 2/8 por la tarde. ¿Qué fracción se bebió en total? ¿Qué fracción queda?

Los problemas ayudan a conectar las operaciones con situaciones reales y a comprobar si el niño entiende qué representa cada fracción.

Por qué las fracciones resultan difíciles

Con números naturales, un número mayor suele representar una cantidad mayor. En fracciones, esa intuición no siempre funciona: 1/8 es menor que 1/4 aunque 8 sea mayor que 4. Por eso es importante construir una comprensión nueva.

Preguntas frecuentes sobre fracciones

¿Qué es una fracción?

Una fracción representa una o varias partes de un todo dividido en partes iguales. El numerador indica cuántas partes se toman y el denominador cuántas partes iguales forman el todo.

¿Cómo se suman fracciones?

Si tienen el mismo denominador, se suman los numeradores y se mantiene el denominador. Si son distintos, primero se buscan fracciones equivalentes con un denominador común.

¿Cómo se restan fracciones?

Con el mismo denominador se restan los numeradores. Con denominadores diferentes, primero hay que expresar las fracciones con un denominador común.

¿Cómo se multiplican fracciones?

Se multiplica numerador por numerador y denominador por denominador, simplificando cuando sea posible.

¿Puede la IA ayudar a aprender fracciones?
